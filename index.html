Como criar o token (uma vez só)
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → sobe_painel.
  3. Permissions: Contents: Read and write e Actions: Read and write (para disparar a coleta na hora).
  4. Cole o token aqui. Ele fica só no seu navegador e não dá acesso a nenhum repo de cliente.
